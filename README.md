# Connect: first principles at work

Six short interactive exercises, plus a capstone, that connect everyday problems to school ideas and the way engineers, scientists and designers handle the same things at work.

Live site: https://gisc.github.io/connect/

No build step, no dependencies, no accounts. Open `index.html`, or serve the folder with any static file server. Progress is saved in the visitor's own browser.

Inspired by engineer Lauren Tan's conference talk [All Code Is Slop (Except Mine)](https://ai.engineer/code/2026/talks/lauren-tan) at AI Engineer CODE 2026. The exercises are original designs for learners; the industry examples are simplified illustrations, not claims from the talk. Illustrations are AI-generated for this series.
